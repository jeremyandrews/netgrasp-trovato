Nothing here reaches for the Item shape. =========================================================================== Security flagging =========================================================================== A security event is flagged wherever it appears, not only on /events/security. A spoof scrolling past unmarked in the main log is the thing this page exists to prevent, and the reader should not have to know to go looking on a second page. The list below is the daemon's own idea of which event types are security relevant, and it is now written in three places: here, in the `ng_event_security` gather's `in` filter (002_netgrasp_gathers.sql), and in netgrasp_core::model::SECURITY_EVENT_TYPES. A unit test in the plugin asserts this file lists every one of them, the same way another asserts it of the migration. Adding a type to the daemon and to none of the three is the drift those tests exist to catch. #} {% set ng_security_types = ["arp_scan", "arp_spoof", "gratuitous_arp", "identity_change", "ip_conflict", "rogue_dhcp"] %}
