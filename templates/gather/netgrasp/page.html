{# The shared chrome for every netgrasp gather page. All nine `gather/query--ng_*.html` templates extend this one. It owns the heading, the empty state, the pager, the stylesheet and the two scripts, so that the nine pages match each other by construction rather than by nine people remembering to keep them the same. =========================================================================== The row shape, which every child depends on =========================================================================== Seven of these nine gathers read a RECORD type, and a record gather yields one flat object per row keyed by the PHYSICAL column name of the base table — `row.mac`, `row.last_ip`, `row.owner_item_id`. It is NOT the Item shape: there is no `row.fields` and no `row.title`, and reaching for one is not a cosmetic error. An undefined variable aborts the whole Tera render, and the route then falls back to the kernel's built-in dump of every column of the base table, daemon internals included. That is what seven of these pages were before this file existed. `gather/query--ng_person_list.html` is the exception: people are Items, so that one page really does get `row.title`. It says so in its own comment. =========================================================================== Blocks a child fills =========================================================================== - `summary` — an optional line above the table (the device pages count states here). - `results` — the table or list itself. Rendered only when there are rows; the empty state below covers the other case, so no child repeats it. - `empty` — an optional extra hint under the gather's own empty text. #}
