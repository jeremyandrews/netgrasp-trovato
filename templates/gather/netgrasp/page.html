{# The shared chrome for every netgrasp gather page. Every `gather/query--ng_*.html` template extends this one. It owns the heading, the empty state, the pager, the stylesheet, the script and the auto-reload interval, so that the pages match each other by construction rather than by nine people remembering to keep them the same. Everything here is served out of the netgrasp repository's own `templates/` and `static/` directories, appended to Trovato's `TEMPLATES_DIR` and `STATIC_DIR` search paths. Nothing in this directory is copied into a Trovato checkout and nothing here requires a change to one. =========================================================================== The row shape, which every child depends on =========================================================================== Seven of these nine gathers read a RECORD type, and a record gather yields one flat object per row keyed by the PHYSICAL column name of the base table — `row.mac`, `row.last_ip`, `row.owner_item_id`. It is NOT the Item shape: there is no `row.fields` and no `row.title`, and reaching for one is not a cosmetic error. An undefined variable aborts the whole Tera render, and the route then falls back to the kernel's built-in dump of every column of the base table, daemon internals included. That is what seven of these pages were before this file existed. `gather/query--ng_person_list.html` is the exception: people are Items, so that one page really does get `row.title`. It says so in its own comment. =========================================================================== Blocks a child fills =========================================================================== - `tabs` — the section's tab strip, under the heading. Drawn whether or not there are rows, since an empty tab is still a tab somebody has to be able to leave (gather/netgrasp/tabs.html). - `summary` — an optional line above the table (the device pages count states here). - `results` — the table or list itself. Rendered only when there are rows; the empty state below covers the other case, so no child repeats it. - `empty` — an optional extra hint under the gather's own empty text. #} {# =========================================================================== The auto-reload interval, in seconds. THIS LINE IS THE KNOB. =========================================================================== Ten seconds by default. `0` switches the reload off. A `?refresh=` query string overrides it for one page load, which is how an interval gets tried, and switched off, without editing anything. Why the default lives in a netgrasp template rather than in site configuration: a gather content template is rendered in its own Tera context holding `query`, `rows`, `filter_values` and `base_path`. The site context that carries site configuration is injected into the *page* template around this one, not into this one. The three routes that could carry a number in here instead are all closed: - `query.display` deserializes into a typed kernel struct (`QueryDisplay`), so an extra key written into that jsonb by a netgrasp migration is dropped rather than reaching the template. - the site-wide setting a `refresh_seconds` context variable would read does not exist in the kernel, and inventing one is a change to Trovato. - reusing an existing typed field (`header`, `empty_text`) to carry an integer is a lie in the schema. So the honest netgrasp-only answer is a literal in netgrasp's own chrome, which the operator owns: this file lives in the netgrasp checkout that the deployment's TEMPLATES_DIR points at. #} {% set ng_refresh = 10 %}
