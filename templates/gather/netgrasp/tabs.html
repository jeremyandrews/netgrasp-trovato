Comings and goings is a tab of both People and Activity; its own page draws Activity's. Why tabs and not a second menu level: the kernel never draws a child menu entry (docs/UI.md, "Why tabs on the page, not a second menu level"), and its active-link check is an exact path match, so the site menu cannot say which of a section's pages is open. These can, because each tab is its own gather and the page knows which gather it is. Set `ng_tabs` to the section before including this: {% set ng_tabs = "activity" %}{% include "gather/netgrasp/tabs.html" %} The active tab is the one whose gather is this page's (`query.query_id`). A page that is in the section but is none of its tabs (one person's devices, one device's events) draws the strip with nothing marked, which is still the way back. The path is printed `safe` because it is a literal written above, never anything a request supplied, and escaped it would read `/activity`. Each tab is one "gather|path|label" string rather than a nested array, because a Tera array literal holds literals and not other arrays. Plain links, so the strip works with scripting off.
