The four differ only in which rows the gather selects, so they have no business differing in how a row is drawn — and a column added to one copy of four is a column missing from three. Rows are `ng_device_state` records: flat objects keyed by the physical column names of ng_devices. See gather/netgrasp/page.html for what happens when a template forgets that. =========================================================================== The Where column exists only when something on the page is somewhere =========================================================================== `current_location` and `current_ap` come from the daemon's UniFi enrichment, and with enrichment off (the default, and most installs) both are null on every row. A column of dashes on every device page would say "missing" about a feature that is simply not switched on, so the column, header and cells alike, is rendered only when at least one row on this page has either value. Counted with `map`, which drops nulls, so the length is the number of rows that actually have one. Not `filter`: it matches a value and cannot express "not null". Bound here, at the top level of the template, because a `set` inside the row loop would not be visible to the header above it. #} {%- set ng_with_location = rows | map(attribute="current_location") | length -%} {%- set ng_with_ap = rows | map(attribute="current_ap") | length -%} {%- set ng_located = ng_with_location + ng_with_ap > 0 -%}

The chip is still the fallback, for the case the view cannot resolve: a device naming an owner whose mirror row is gone. Showing the id then is better than an empty cell — it is the only handle on a dangling reference anybody has. The chip shows the *last* group of the uuid, not the first. These ids are UUIDv7: the leading bytes are a timestamp, so two people created in the same millisecond — which is what happens when they are seeded together — share the first eight characters exactly and the chip distinguishes nothing. The final group is the random one. The full id is in the title either way. #} {# The epoch twin, not `last_seen_at`.
